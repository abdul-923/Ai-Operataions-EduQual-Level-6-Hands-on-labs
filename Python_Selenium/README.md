
# Python Selenium Automation Labs

## Overview

This repository contains my hands-on Python Selenium automation labs and mini projects.

I created these labs to build a practical understanding of web browser automation using Python and Selenium WebDriver. I started with basic browser automation and gradually moved toward more advanced Selenium concepts and complete end-to-end automation projects.

Throughout these labs I practiced locating web elements, interacting with forms and buttons, handling waits and alerts, working with multiple browser windows, using iframes, running Selenium in headless mode and building complete automation workflows.

### End Mini Projects
* 16_End_Mini_Project

These projects allowed me to combine multiple Selenium concepts into practical end-to-end automation workflows.

## Environment Setup

I used a Python virtual environment to keep the Selenium dependencies organized.

The main virtual environment is located in the Python_Selenium directory and is reused across the different labs.

Basic setup:

* Activate the virtual environment
* Install Selenium
* Launch Chrome
* Run the Python Selenium scripts

## Learning Progression

The labs follow a gradual progression:

**Browser Automation → Element Locators → User Interaction → Forms → Validation → Waits → Screenshots → Dropdowns → Alerts → Multiple Windows → Iframes → Headless Automation → End-to-End Projects**

This helped me move from understanding individual Selenium commands to combining them into complete browser automation workflows.

## Mini Projects

The mini projects were especially useful because they required combining several concepts together.

For example the Login and Shopping Cart Automation project follows this workflow:

**Open Website → Login → Verify Login → Find Product → Add Product to Cart → Open Cart → Verify Product → Take Screenshot → Validate Result → Close Browser**

This gave me practical experience with how Selenium can be used to automate a complete user journey rather than just testing individual elements.

## Conclusion

This repository represents my hands-on learning journey with Python Selenium automation.

I started with basic browser control and element locating and gradually progressed to handling dynamic elements, browser windows, alerts, iframes and headless execution.

I also built end-to-end mini projects where I combined multiple Selenium concepts to automate realistic user workflows.

The main goal of this repository is to continue improving my practical skills in **Python, Selenium WebDriver and automated web testing** through hands-on projects and experimentation.
