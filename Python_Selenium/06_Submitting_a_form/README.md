
# Lab 6: Submitting a Form

## Overview

Today I successfully performed this lab on submitting an HTML form.

In this lab, I created a simple HTML form with name and email fields and a Submit button. I then used JavaScript to handle the form submission and used Python Selenium to automate entering the information and submitting the form.

The lab helped me understand the basic flow of how a web form works and how Selenium can automate the same actions that a user normally performs in a browser.
