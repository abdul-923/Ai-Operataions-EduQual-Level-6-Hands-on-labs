
# Lab 5: Clicking a Button with Selenium

## Lab Overview

This lab demonstrates browser automation using Python and Selenium by locating a button on a local HTML webpage, clicking it automatically, and verifying the result.

## Objectives

- Create a simple HTML webpage with a button.
- Identify the button using its ID.
- Open the webpage using Selenium.
- Locate the button using Selenium.
- Click the button automatically.
- Verify the result after clicking.
- Close the browser automatically.

## Technologies Used

- Python 3
- Selenium
- Google Chrome
- HTML
- Ubuntu Linux
- Python Virtual Environment

## Files Included
