

# 07 - For Loop

## Overview

This lab demonstrates how to use a **for loop** in Bash scripting. The script accepts multiple names from the user and greets each person one by one using a loop.

## What I Practiced

* Creating a Bash script
* Taking multiple names as user input
* Using the `read` command
* Using a `for` loop
* Looping through multiple values
* Printing output with `echo`

## Commands Used

* nano lab.sh
* chmod +x lab.sh
* ./lab.sh

## Sample Input

* ali anna sara

## Sample Output

* Hello, ali!
* Hello, anna!
* Hello, sara!

## Learning Outcome

In this lab, I learned how to use a **for loop** to repeat the same task for multiple values. The script reads a list of names entered by the user and greets each name individually. This helped me understand how loops automate repetitive tasks in Bash scripting.
