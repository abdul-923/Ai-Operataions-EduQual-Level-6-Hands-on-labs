

# Bash Scripting Lab 12 – Arrays

## Lab Overview

This lab demonstrates how to create, access, iterate, and update arrays in Bash scripting. It covers the basics of array manipulation using loops and shows how to append new elements to an existing array.

## Files Included

* arrays.sh – Bash script containing array operations
* README.md – Lab documentation
* Screenshots – Terminal output and script execution

## Concepts Covered

* Creating an array in Bash
* Printing all array elements
* Iterating through an array using a for loop
* Using the @ operator to access all elements
* Adding a new element to an existing array
* Displaying the updated array

## Commands Used

* mkdir
* cd
* nano
* chmod +x
* ./arrays.sh
* bash arrays.sh
* echo
* for
* do
* done

## Expected Output

* Displays the original array of fruits
* Prints each fruit individually using a loop
* Adds a new fruit to the array
* Displays the updated array containing the new element

## What I Learned

* How to create arrays in Bash using parentheses
* How to access all array elements using '${array[@]}'
* How to iterate through arrays with a 'for' loop
* How loop variables receive one array element at a time
* How to append new elements to an existing array using the '+=' operator
* How to print the updated array after modification

Create an array → Print all elements → Loop through each element → Add a new element → Print the updated array.
