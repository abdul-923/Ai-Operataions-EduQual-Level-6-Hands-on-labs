

05 - If Else Statement

Overview

This lab demonstrates how to use the if-else statement in Bash to check whether a file exists. The script accepts a filename from the user using the read command and displays a message based on whether the file is found in the current directory.

What I Practiced

- Creating an interactive Bash script
- Reading user input using the read command
- Storing user input in a variable
- Using the if-else conditional statement
- Using the -f file test operator to check whether a file exists
- Displaying different messages based on the condition
- Running executable Bash scripts

Learning Outcome

In this lab, I learned how to use the if-else statement to make decisions in a Bash script. I also learned how to accept a filename from the user using the read command and verify whether the file exists using the -f test operator. This helped me understand how Bash scripts can perform different actions based on conditions and user input.
