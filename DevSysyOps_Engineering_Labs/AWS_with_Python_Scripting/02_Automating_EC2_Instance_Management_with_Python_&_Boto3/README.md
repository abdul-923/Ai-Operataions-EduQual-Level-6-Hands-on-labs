

# Lab 2 – Automating EC2 Instance Management with Python and Boto3

## Overview

Today I practiced automating EC2 instance management using Python and Boto3. I created a Python script to start and stop my EC2 instance and monitor CPU utilization through CloudWatch. I also added a menu to choose different operations from the terminal.

## Files Included

- ec2_manager.py
- Readme.md
- screenshots
- commands history
## Commands Used

- python3 -m venv .venv
- source .venv/bin/activate
- python -m pip install boto3
- nano ec2_manager.py
- python ec2_manager.py

## Output

- Python virtual environment created successfully
- Boto3 installed successfully
- EC2 instance state checked successfully
- EC2 start and stop operations implemented
- CloudWatch CPU monitoring implemented
- Interactive menu displayed successfully

## What I Learned

- How to manage EC2 instances using Python
- How to use Boto3 to communicate with AWS
- How to check the state of an EC2 instance
- How to retrieve CPU utilization from CloudWatch
- How to use Python functions and conditional statements
- How to create an interactive menu using a while loop

## Conclusion

In this lab I learned how to automate EC2 instance management using Python and Boto3. I created a script to start and stop an instance and retrieve CPU utilization through CloudWatch.
