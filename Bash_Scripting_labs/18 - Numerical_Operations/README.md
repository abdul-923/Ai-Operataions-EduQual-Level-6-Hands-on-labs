
# Bash Arithmetic Operations Lab

## Overview

This lab demonstrates basic arithmetic operations in Bash scripting. The script takes two numbers from the user and performs addition, subtraction, multiplication, division, and a calculation using bc. It also includes a check to prevent division by zero.

## Files Included

* script.sh — Bash script containing the arithmetic operations
* README.md — Documentation for the lab
* screenshots — Lab execution and output screenshots

## Commands Used

nano script.sh

chmod +x script.sh

./script.sh

bash script.sh

## What the Script Does

* Takes the first number from the user
* Takes the second number from the user
* Performs addition
* Performs subtraction
* Performs multiplication
* Performs calculation using bc
* Performs division
* Checks for division by zero
* Displays the results

## Key Learning

This lab demonstrates how Bash handles user input, variables, arithmetic operations, bc calculations, and conditional checks for safe division.
